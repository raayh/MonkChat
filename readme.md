# 📁 MonkChat – Chatbot com Fluxos Personalizados

Projeto desenvolvido durante o curso técnico com o objetivo de aplicar conceitos de UX conversacional, criação de fluxos de atendimento automatizado e integração de tecnologia chatbot para resolução de problemas comuns.

## 💡 Funcionalidades

- Chat em tempo real
- Login com nickname 

## 🔧 Tecnologias Utilizadas

HTML, CSS e JavaScript

## 🧪 Como Executar o Projeto
1. Clone o repositório:
```
git clone https://github.com/raayh/MonkChat.git
```

3. Abra o arquivo index.html diretamente no navegador.

_Não é necessário instalar dependências ou rodar servidor local._

## 🎯 Objetivo do Projeto

Um sistema de chat online simulado, desenvolvido com HTML, CSS e JavaScript. O objetivo é praticar a criação de interfaces de mensagens, reforçar a manipulação de eventos e aplicar conceitos básicos de front-end em um ambiente leve e funcional.
